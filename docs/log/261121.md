## v3.3.1 设置「样式默认」背景色改调色盘取色

> 创建于 2026-11-21 09:53

**需求**（会话确认）：设置窗口「样式默认」的背景 RGB 改成与辅助便签一致的调色盘取色方式，不再用三个数值输入框；六个玫红同源样例色保留。

**实现**（spec/plan：`docs/project/便签/2026-11-21-v3.3.1-style-default-picker-{design,plan}.md`）：

- `frontend/index.html`：「背景 RGB + bg-r/bg-g/bg-b 三个 number 输入」替换为单个 `<input id="bg-color" type="color">`（与辅助便签 1~5 同款，`styleform.css` 既有样式直接覆盖，无新增 CSS）。
- `frontend/assets/settings.js`：`fields` 移除 bgR/bgG/bgB、新增模块级 `bgColor`；`readStyle()` 背景三通道改读 `hexToRgb(bgColor.value)`（复用辅助便签区既有换算函数）；调色盘 `input` 事件实时应用（同 `applyAuxColors` 模式）——因 `applyStyle` 有 `applying` 互斥、快速拖动可能丢最后一次 input，加 200ms 尾随补应用定时器保证最终值落盘；样例色点击 = 写调色盘 value + 清尾随定时器 + 立即应用；`init()` 回填 `rgbToHex({bg_r, bg_g, bg_b})`。
- 数据/后端零改动：`NoteSettings.BgR/G/B`、`ApplyNoteStyle`、settings.json v2 形状全部不动，旧值直接回填调色盘。
- 收尾：`settingsui.Version` → v3.3.1；changelog 顶部补 v3.3.1 条目；CLAUDE.md 补版本段。Service 形状未变，无需重新生成绑定。

**范围说明**：便签上的独立样式面板（note.html）也是 RGB 数值输入，本次按需求只改设置窗口，独立面板留待需要时同款改造。

**测试**：`go build ./...` + `go vet ./...` + `go test ./...` 全绿（纯前端改动，Go 侧仅 Version 常量）。

**状态**：已验收（2026-11-21 手测闸口开发者确认通过）；spec/plan 已归档至 `docs/project/便签/archive/`。
