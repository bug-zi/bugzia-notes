# 261120 开发日志

## v3.3.0 钉住（不受挤压）+ 置顶改名 + 头部「更多」菜单

> 创建于 2026-11-20 01:18

**需求**（会话确认）：便签防重叠挤压落地后，开发者希望主便签固定在原地不受挤压。新增「钉住」（Fixed）语义；原「钉住」（保持最上层）改名为「置顶」；头部按钮收敛为 钉住/置顶/更多 三键（设置/复制/销毁收进更多菜单）。

**实现**（spec/plan：`docs/project/便签/2026-11-20-v3.3.0-pin-immovable-{design,plan}.md`，验收后归档）：

- 数据：`NoteRecord.Fixed bool`（json `fixed`），notes.json 版本保持 v3——可选 bool 缺省零值即 false，零迁移零重写；`Pinned` 字段名与 JSON 键不动（避免大面积重命名），注释改「置顶」。
- 挤压链路：`PushNote.Fixed` 标志；`ResolveOverlaps` 把钉住矩形**预先并入 `landed` 作静态障碍**并直接标记已处理——不进扫描循环、永不被推、失败不置 packed（塞不下见证只来自可推便签；被钉住堵死的可推便签无解仍照常 packed）。滑移越障与装箱复核都以 landed 为障碍集，被弹者落点自然避开钉住矩形。
- 控制器：`ToggleFixed` 镜像 `TogglePinned`（刷 UpdatedAt）；`WindowOps.SetFixed` 只发前端同步事件（无窗口层变化）；事件链 `note:fixedtoggle` → `ToggleFixed` → `note:fixed-sync`；hydrate 载荷加 `fixed`。主动方（含钉住便签被拖动）无特殊化——自己拖动照常挤开别人。
- 前端（经手测反馈修订：置顶低频收进菜单、复制高频提回头部）：头部三键 钉住(btn-fix)/复制(btn-copy 提回头部)/更多(btn-more)；btn-pin/btn-style/btn-destroy 挪进 `.note-moremenu` 下拉（面板底色 `--note-bg` 与便签背景一致、no-drag）；激活态字色复用 `--note-pin-ink`（btn-fix/btn-pin 同 class `pin`）。菜单交互：btnMore 开合（stopPropagation 防文档级监听立即收掉）、点空白/Esc 关闭、与样式面板互斥（openMenu 关面板、requestDestroy/openPanel 关菜单）、bodyEl 既有 click 监听开头加 menuOpen 守卫（同元素监听按注册顺序执行，守卫必须写在原监听内才能拦住编辑入口）。踩坑：`.note-moremenu` 的 `display:flex` 会压过 `hidden` 属性的 UA 默认样式导致菜单默认外露——显式补 `.note-moremenu[hidden]{display:none}`。
- 收尾：`settingsui.Version` → v3.3.0；changelog 补条目；设置窗口集合切换帮助文案「未钉住的自动钉住」→「未置顶的自动置顶」。settingsui.Service 形状未变，无需重新生成绑定。

**测试**：新增单测 9 个——store round-trip 固定字段 + 旧 v3 文件缺键读 false；`ResolveOverlaps` 钉住三分支（不被推无 packed / 落点避钉住下弹 (58,166) / 全屏钉住堵死可推者照常 packed）；控制器 `ToggleFixed` 翻转与通知、拖拽压钉住不动（兄弟 (250,478) 下弹）、拖动钉住自身照常挤开 (250,378)、召唤压钉住接受重叠。`go build ./...` + `go vet ./...` + `go test ./...` 全绿。
