## v2.3.0 立项与实施：召唤智能避重叠

> 创建于 2026-11-19 12:24

**需求**：开发者提出 v2.3.0 更新计划——召唤便签时若原位置已被其他便签占据，去桌面找空余位置放置；实在无法避免再原位叠放且保证在最上层。空余 = 只看便签占据（不管应用窗口）。brainstorming 确认：三召唤入口统一（辅助槽位键/集合切换键/新建键召唤）、空位策略复用 PackTopLeft 左上装箱扫描、未钉便签维持沉底语义不为例外（钉住态才保证置顶）。产出 spec/plan：`docs/project/便签/2026-11-19-v2.3.0-summon-overlap-avoid-{design,plan}.md`。

**实施**（TDD 内联执行）：`layout.go` 加 `rectsIntersect`；`WindowOps` 加 `MoveNote`（wailsOps 实现带 `suppressMove` 抑制标记——`WindowDidMove` 见标记跳过 `NoteMoved`，防程序性位移被记为用户拖动；`SetPosition` 返回后标记仍在则兜底清除防吞真实拖动）；`controller.go` 加 `originLocked`/`obstacleRectsLocked`/`summonNote`（三情况判定：原位无重叠原位、被占装箱找空位+落点复核、屏幕满原位叠放；位移只更新实时 px/py 不写 rec.X/Y），三召唤入口统一接线。实施中回归抓到一个 bug：`summonNote` 初版绕过 `showNote` 漏记权威可见表 `visible[id]=true`（新单测只断言 fakeOps 侧没抓到，`TestMaxNotesCapTwenty` 抓到）已修复；连召测试期望值修正（主便签在下行带不阻第一行装箱，f2 正确落点 580,8）。单测 7 项：三情况、负坐标原位、隐藏不算障碍、集合连召逐张避让链、矩形相交五例。`Version` → v2.3.0，`changelog.js` 补条目；无服务方法变更，绑定无需再生成。

**验证**：`go build/vet/test` 全绿。首测反馈「召唤仍叠放」，系统化排查：先读 Wails 源码排除三嫌疑（SetPosition 隐藏窗口失效 / 坐标空间物理与 DIP / Show 重放坐标——SetPosition 走 `DipToPhysicalRect` 与装箱同坐标系、`show()` 为裸 `SW_SHOW` 不重放坐标），再边界埋点（`[summon]`/`[move]` 日志）复测——定位为**测到旧稳定版 exe**（v2.2.1 不含新逻辑），dev 版实测正常，非代码 bug。诊断日志收敛为 `[summon]`（判定结果）+ `[move]`（位移回读）两行常驻（对齐 `[hydrate]` 先例）。手测闸口（三入口×三情况、避让后拖动重启恢复、真实拖动不被抑制吞、更新日志高亮）开发者确认全部通过。收尾：CLAUDE.md 同步（概述 v2.3.0 行、召唤避重叠领域规则、测试策略、手测闸口）；spec/plan 移入 `docs/project/便签/archive/` 并加已归档行。

## v3.0.0 立项与实施：召唤弹开式避重叠

> 创建于 2026-11-19 14:47

**需求**：开发者多轮实测后提出——v2.3.0 只在大部分重叠时避让、部分重叠常保持叠放；期望反转为「召唤便签原位落地，把重叠便签向右/下弹开（带动画），最大限度平铺不重叠，实在放不下才允许重叠」。定为 v3.0.0。brainstorming 四决策：兜底=被弹者装箱找空位（屏幕满才接受重叠）、弹后位置记住（placed 写 rec、哨兵保持哨兵）、连召互相弹开+批次按 UpdatedAt 升序落地（最活跃者最后落地必保原位）、级联传导机制。产出 spec/plan：`docs/project/便签/2026-11-19-v3.0.0-summon-push-away-{design,plan}.md`。

**Phase 0 取证**（plan Task 1）：诊断日志复现 12 次召唤全部判定正确——「部分重叠不移开」真身是 v2.3.0 兜底链局限：用户便签普遍大于默认尺寸（400~456 宽、300~678 高），装箱行带稀疏，PackTopLeft 对大便签几乎必然无解 → 频繁落入「接受重叠」分支。检测/同步层无 bug（px/py 全程同步、SetPosition 精确到位），计划中的 RefreshGeometry 校准分支不采用（避免投机代码）。

**实施**（TDD 内联）：`push.go` 纯函数 `ResolveOverlaps`（右/下/左/上迭代越障取最小位移、平手偏右下、8px 间隙、装箱兜底、接受重叠、级联有界）+ 7 项单测（其中级联链/装箱兜底两组期望值首版推演漏算级联语义，按实现验证后修正——行为优于预期：滑动级联优先于装箱）；三入口 `summonNote` 重写为「原位落地 + pushPass」（状态先写：px/py + placed 补写 rec.X/Y、不刷 UpdatedAt，动画纯视觉追赶）；`WindowOps` 换形 `MoveNote` → `GlideNote`（250ms easeOutCubic、16ms 步进、40ms 瀑布错峰、同窗口取旧起新）；`suppressMove` 所有权改为动画持有者（事件回调只读，animMu 护 map、SetPosition 锁外防死锁）；`ToggleMainSet` 批次 UpdatedAt 升序。连召互推单测再次暴露期望值漏算级联（f2 被弹到 f1 现位 → f1 二次级联），修正后全绿。

**验证**：`go build/vet/test` 全绿。手测闸口（spec §7 九项：三入口弹开动画/级联传导/兜底链/连召互推/部分重叠触发/弹后重启/缩放尺寸/拖动缩放不受扰/更新日志高亮）待开发者实机确认；通过后补 CLAUDE.md 并归档 spec/plan。
