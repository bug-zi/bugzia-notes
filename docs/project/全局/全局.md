# 全局

跨模块与应用级改动的 spec/plan 存放目录。

**使用方式**：brainstorming / 写计划会话产出的设计记录（`YYYY-MM-DD-<主题>-design.md`）与实施计划（`YYYY-MM-DD-<主题>-plan.md`）存放于此，落地或废弃后移入 `archive/`；存放与归档机制见 [`../README.md`](../README.md)。

**边界**：单模块专属的 spec/plan 随该模块的 design.md / designs-specs.md 就地存放，不放这里；archive/ 内文档只读参考，回改走 README.md 的回改通道。
