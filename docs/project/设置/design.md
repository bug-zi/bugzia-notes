# 设置（设置窗口）

介绍：应用的设置入口窗口，管理便签默认样式、全局快捷键重绑与通用项；改动实时生效。
本文档由 AI 根据已批准的 v1 主体设计（`../全局/archive/2026-11-16-bugzia-notes-app-design.md`）与已批准待实现的自启动设计（`../全局/2026-11-17-autostart-silent-boot-design.md`）起草，**当前为草稿待开发者审核**，审核定稿后为需求正本。

v1（草稿待审核）：

**样式设置：**

- 便签默认样式可视化配置（底色 / 文字色 / 透明度 / 圆角 / 字号 / 尺寸），改动对全部便签实时生效
- 首次启动检测到 bugzia 配置且本应用无配置时，自动一次性迁移便签样式；与 bugzia 数据互不读写

**快捷键重绑：**

- 三键（集合切换 / 直接新建 / 销毁当前）可在设置中重绑，重绑后立即生效（Win32 RegisterHotKey 卸载重注册）
- 默认键位：bugzia 迁移值；无迁移时 `alt+n` / `alt+shift+c` / `alt+z`

**通用（自启动，设计已批准待实现）：**

- 设置窗口新增「通用」区：「开机自启动」开关，状态实时读写
- 开 = 写 HKCU Run 键（带引号 exe 路径 + `--silent`）；关 = 删除值（值不存在视为成功）
- 开机自启恒为静默启动（仅托盘、便签窗口隐藏预建，召唤零延迟）；手动启动恒为正常显示全部钉住便签
- 详细机制、自愈与已知限制见 `../全局/2026-11-17-autostart-silent-boot-design.md`

**边界：**

- 不提供「自启动时是否静默」选项（行为按已批准决策固定）
- 不感知任务管理器「启动应用」的禁用态（明示接受的已知限制）
