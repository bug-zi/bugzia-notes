# bugzia-notes 设计 — v4.1.0 便签局部设置新增 MD 渲染（Markdown 富文本呈现）

> 创建于 2026-11-26 09:00（会话需求确认）。维护权责见 `docs/project/README.md`。
> 前置：v4.0.1（已验收）。全局设置不涉及（会话确认：仅局部面板）。

## 1. 背景与目标

每张便签的局部「设置」面板（note.html `.note-stylepanel`）当前只有样式锁 + 样式项。目标（会话确认）：

1. 面板新增**「MD 渲染」开关**：开启后该便签阅读态内容以 Markdown 富文本呈现，编辑与存储仍是 MD 源码（content 语义不变，关掉开关即回纯文本原样）。
2. 适用范围：**辅助便签（slot 1~5）与自由便签（slot -1）**；主便签（slot 0）不开放——它是结构化待办视图（【分类】分区 + 勾选框），与 MD 渲染语义冲突，面板不显示此开关。
3. 渲染引擎采用**手写迷你渲染器**（会话确认）：零第三方依赖、离线可靠、先整体转义再打标记天然防注入，符合项目「无构建链、轻依赖」风格。
4. 渲染后链接点击用**系统默认浏览器打开**（会话确认），便签窗口不导航。

方案取舍（已定）：只替换阅读态渲染方式（`render()` 分流），编辑链路完全复用现有「点正文进 textarea 编辑源码 → 失焦提交 / Esc 取消」模型。否决编辑态分屏预览（窗口太小）与 contenteditable 所见即所得（源码往返转换破坏手写格式）。

## 2. 数据模型（notes.json v3 增量，零迁移）

1. `NoteRecord` 增字段 `MDRender bool`，json tag `md_render`，缺省 false——与 v3.3.0 `fixed` 完全同模式：旧 v3 文件缺键读 false、不重写文件、round-trip 保留。
2. 无全局设置项；settings.json 不动。

## 3. Go 侧改动

1. `Controller.SetMDRender(id string, on bool) error`：翻转 `rec.MDRender` + 刷 `UpdatedAt`（同 `ToggleFixed` 先例：呈现方式变更视为编辑，影响召唤活跃度排序）→ `Hydrate` 单窗重推 + 防抖落盘。Go 不拦 slot=0（入口在前端隐藏即可，控制器保持简单）。
2. `WindowOps.Hydrate` 载荷扩带 `md_render`（`wailsOps.Hydrate` 与内存替身同步改）；前端据此分流渲染 + 回填面板开关态。
3. `settingsui.Service.SetMDRender(id, on)` 薄封装（同 `SetNoteStyleLock`）；改服务后 `wails3 generate bindings` 重新生成绑定。
4. main.go 新订阅事件 `note:openlink {id, url}` → `application.BrowserOpenURL(url)`（API 签名以 `%GOPATH%/pkg/mod` 模块源码核实为准，不凭记忆）；url 只接受渲染器放行的 http/https。

## 4. 迷你渲染器（新文件 `frontend/assets/md.js`）

1. 支持子集（会话确认范围）：
   - 块级：标题 `#`~`######`；围栏代码块 ` ``` `（语言标注不高亮）；引用 `>`；无序 `-`/`*` 与有序 `1.` 列表（缩进嵌套）；分隔线 `---`/`***`；段落（连续非空行）。
   - 行内：粗体 `**x**`、斜体 `*x*`、行内代码 `` `x` ``、链接 `[text](url)`。
   - 段内换行：硬换行 `<br>`（换行即显，贴合便签使用习惯，非标准合并语义）。
   - 不支持（明确排除）：表格、任务列表 `- [ ]`、图片、删除线、代码高亮、引用嵌套套列表等复杂组合（后续需要再扩展）。
2. 安全策略（核心）：所有文本**先整体 HTML 转义再打标记**——`<script>` 天然变纯文本；链接 href 只接受 `http://` / `https://` 前缀，其余按普通文本渲染（防 `javascript:` 注入）。
3. 渲染输出写入 `textEl.innerHTML`；`render()` 分流：`mdOn ? innerHTML = mdRender(content) : textContent = content`。
4. 编辑链路零改动：点正文进 textarea 编辑的是 MD 源码，`commitEdit` 后重新分流渲染；IME、`syncTextareaHeight`、`note:changed` 通道照旧。
5. 渲染态链接点击：拦截 `<a>` 默认导航，`wails.Events.Emit("note:openlink", { id, url })`。

## 5. 前端接线（note.html / note.js / note.css）

1. 样式面板 form 加一行「MD 渲染」开关（`<input type="checkbox">` + label，与面板既有表单控件同风格）：仅 `slot !== 0` 显示（`openPanel` 里与 catspanel 反向显隐）；与样式锁**独立**，不要求先锁样式。
2. 开关点击 → `Call.ByName(NS + "SetMDRender", id, on)`（同 `SetNoteStyleLock` 调用模式）；失败回弹 + `sp-msg` 行内报错。
3. hydrate 读 `md_render` 存 `mdOn` 状态；若处于编辑态，渲染在 `commitEdit` 后的 `render()` 自然生效。
4. 复制按钮仍复制源码 content；「已钉住/已置顶」字色等既有逻辑不受影响。
5. note.css 富文本样式（`.note-text` 内 MD 元素）：全部半透明白系（`rgba(255,255,255,…)`）与任意便签底色协调（硬性规则 3，禁高饱和撞色）；标题字号用 `em` 相对基准（约 1.6/1.4/1.2/1.1 倍递减），自动跟随字号设置；代码块半透明白底圆角、引用左侧竖线、列表缩进、链接下划线。图标不用 emoji（硬性规则 2）。

## 6. 测试

1. Go 单测：`SetMDRender` 翻转/防抖落盘/刷 UpdatedAt/Hydrate 载荷带 `md_render`；旧 v3 记录缺 `md_render` 键读 false 且 round-trip 保留（WindowOps 内存替身，模式同 `ToggleFixed`）。
2. 手测闸口（全部通过才算交付）：
   - 开关即时切换：开 = 富文本、关 = 回纯文本原样；
   - 源码编辑往返：点正文改源码 → 失焦 → 渲染更新；Esc 取消回到改动前；
   - 子集各元素渲染正确（标题层级/粗斜体/行内码/代码块/列表嵌套/引用/链接/分隔线/硬换行）；
   - XSS 输入被转义（`<script>` 显示为文本、`javascript:alert(1)` 链接不执行）；
   - 链接点击系统浏览器打开、便签窗口不导航；
   - 重启恢复开关态；主便签面板无此开关；
   - 回归：样式面板既有功能、复制、编辑（点正文/失焦/IME）不受影响。
