# bugzia-notes 设计 — v3.2.0 满屏熔断（挤开防抖）

> 创建于 2026-11-19 23:40（会话需求确认；同夜修订——首版「让位预算」设计经开发者验收否决：它把空闲桌面应有的连续挤开也禁掉了，修正为满屏熔断设计）。维护权责见 `docs/project/README.md`。
> 已归档：261119 随 v3.2.0 落地（手测闸口开发者确认通过）。
> 前置：`archive/2026-11-19-v3.1.0-drag-push-away-design.md`（已验收发布）。

## 1. 背景与目标

v3.1.0 拖拽挤开实测：便签多到桌面装不下时，拖动会话的 50ms 采样不断把被压便签重新弹开（被弹者落点常仍在拖动方向上，追压再弹循环往复），拥挤区域出现「所有便签互相碰撞持续移动停不下来」。目标行为（会话确认）：**桌面空闲时保持 v3.1.0 的实时挤开（永不重叠、推实物手感，可无限重复弹开）；桌面塞不下时不再持续移动——允许覆盖、快速静止**。任何情况下不允许便签持续不停的运动。

## 2. 行为规则（会话确认）

1. **桌面空闲（弹开与装箱总能找到落位）**：拖动/缩放中无限实时挤开，行为与 v3.1.0 完全一致——每张便签可被多次弹开，追压追弹的推实物手感保留。
2. **满屏见证**：`ResolveOverlaps` 对某张便签「右/下/左/上四向弹开 + 装箱兜底」全部无解、只能接受重叠时，即认定「桌面塞不下」——装箱都找不到空位 = 桌面放不下该矩形，是结构性信号而非启发式阈值（不采用面积比例等拍脑袋判定）。
3. **熔断**：同一手势内第一次出现接受重叠 → 本手势立即进入**满屏模式**：此后所有便签不再被弹开，拖动 A 与任何便签的重叠都被接受，立即静止。
4. 满屏模式作用域 = 当前手势会话；**下次手势开始（`BeginDragSession`）重置并重新评估**。
5. 松手兜底（`NoteMoved`/`NoteResized` 记账后的弹开）同样受满屏模式约束——满屏松手不引发第二轮挪移。
6. 熔断趟内已成功弹开的便签照常落位（同一趟里成功者落位、失败者接受重叠，之后静止）；被接受重叠者保持原地、不回弹。
7. **召唤弹开完全不受满屏模式影响**（单次动作天然有界；召唤自身的接受重叠也不读不写手势熔断标记）。
8. 其余语义（隐藏不参与、A 永不程序性位移、被弹者持久化、动画、实时尺寸）全部沿用 v3.1.0。

## 3. 机制

- `ResolveOverlaps` 签名改 `ResolveOverlaps(self Rect, notes []PushNote, screenW, screenH float32) (pushes []Push, packed bool)`：接受重叠分支置 `packed = true`（本趟存在「塞不下」见证）；解析逻辑其余不变。
- `Controller.dragPacked bool`（当前手势满屏标记，mu 保护）+ `BeginDragSession()` 重置（main.go 手势 Start 已接线，无需改动）。
- `pushPass(self *NoteLive, trackPacked bool) int`：`trackPacked = true` 时先查 `dragPacked`（已熔断 → 直接返回 0，不做任何解析与移动）；解析后若 `packed` 且 `trackPacked` → 置位标记。召唤路径传 `false`（不读不写）。
- 调用点：`summonNote` → `false`；`DragLiveTick` / `NoteMoved` / `NoteResized` → `true`。
- 并发形态与 v3.1.0 相同（无新增共享 map，布尔标记在锁内置位）。

## 4. 不变的东西

采样机制（50ms 会话 goroutine、四事件订阅）、记账兜底触发点、`GlideNote` 动画、持久化语义、召唤弹开三入口、`WindowOps` 接口（零新增）、`main.go`（`BeginDragSession` 已接线）。

## 5. 测试

单测：

- 纯函数：接受重叠时 `packed=true`（屏幕满几何）；正常弹开 `packed=false`；既有 9 测适配双返回值。
- 控制器：
  - 满屏熔断：首轮 A 压 B（弹开成功）+ 巨型 C 接受重叠（塞不下见证）→ 熔断；A 追压 B → 冻结无弹开、B 保持原位；
  - `BeginDragSession` 重置：新手势恢复解析、B 重新让位；
  - 空闲桌面无限追压追弹（v3.1.0 手感回归，无满屏见证时连续挤开）；
  - 召唤不受 `dragPacked` 影响（熔断后召唤仍照常弹开）。

手测闸口（全部通过才算交付）：

1. 空闲桌面拖动 A：连续实时挤开、永不重叠（v3.1.0 手感回归）。
2. 塞满桌面拖动 A：很快静止、允许覆盖、无持续碰撞移动。
3. 满屏快速甩动后松手：兜底不引发第二轮挪移。
4. 新手势重新评估：再拖可恢复挤开（或再次熔断）。
5. 召唤弹开三入口回归（与 v3.0.0/v3.1.0 一致）。
6. 更新日志弹窗 v3.2.0 条目 + 当前版本高亮。
7. `go build ./...` + `go vet ./...` + `go test ./...` 全绿。
