## 1. 背景与目标

设置窗口「样式默认」区当前用三个数字输入框（`bg-r`/`bg-g`/`bg-b`，0~255）设置主便签背景色，手工输数值不直观。目标（会话确认）：

1. 背景色取色方式改为**调色盘**（`<input type="color">`），与「辅助便签颜色」区同款控件、同款交互。
2. 六个玫红同源样例色按钮**保留**。

## 2. 行为规则

1. 背景色 UI = 单个 `<input id="bg-color" type="color">`（与辅助便签 1~5 同款；`styleform.css` 的 `.row input` 已覆盖色值输入样式，无新增 CSS）。
2. 实时生效：调色盘 `input` 事件触发 `applyStyle`（同辅助便签 `applyAuxColors` 模式）。`applyStyle` 既有 `applying` 互斥在快速拖动取色时会丢弃最后一次改动 → 加 200ms 尾随补应用定时器，保证拖动结束的最终值必落盘。
3. 样例色保留：点击样例 = 把样例色写入调色盘 value + 立即应用 + 清掉待触发的尾随定时器（防冗余重放）。
4. 数据与后端零改动：`NoteSettings.BgR/G/B`（int，0~255）不动；前端复用 `rgbToHex`/`hexToRgb` 换算后仍走 `ApplyNoteStyle`（后端 clamp 已有）；settings.json v2 形状不变，旧值直接回填调色盘。
5. 初始化回填：`GetSettings` 读 `bg_r/g/b` → `rgbToHex` → 调色盘 value。
6. 范围：仅设置窗口；便签上的独立样式面板（note.html 的 RGB 输入）本次不改，留待需要时同款改造。
