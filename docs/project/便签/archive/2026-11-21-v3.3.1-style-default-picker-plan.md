**Goal:** 设置窗口「样式默认」的背景 RGB 三个数字输入改为调色盘（`input[type=color]`），六样例色保留并同步调色盘。

**Architecture:** 纯前端改动（index.html + settings.js）；数据模型、后端服务、存储形状零改动（`ApplyNoteStyle` 照旧收 bg_r/g/b）。

---

### Task 1: 设置窗口前端

**Files:**
- Modify: `frontend/index.html`（样式默认区）
- Modify: `frontend/assets/settings.js`

- [ ] `index.html`：「背景 RGB + 三个 number 输入」整行替换为「背景色 `<input id="bg-color" type="color">`」+ 背景不透明度（同行）。
- [ ] `settings.js`：
  - `fields` 移除 `bgR/bgG/bgB`，新增模块级 `const bgColor = $("bg-color")`。
  - `readStyle()` 背景三通道改读 `hexToRgb(bgColor.value)`（任一非法仍整体返回 null 不应用）。
  - 新增 `bgApplyTimer` + `applyBgSoon()`（立即应用 + 200ms 尾随补应用）；`bgColor` 监听 `input` → `applyBgSoon`。
  - 样例点击：写 `bgColor.value = rgbToHex(...)` → 清定时器 → `applyStyle()`。
  - `init()` 回填：`bgColor.value = rgbToHex({ r: n.bg_r ?? 201, g: n.bg_g ?? 88, b: n.bg_b ?? 119 })`。
