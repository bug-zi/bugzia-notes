# bugzia-notes 设计 — v3.3.0 钉住（不受挤压）与置顶改名 + 头部「更多」菜单

> 创建于 2026-11-20 00:28（会话需求确认）。维护权责见 `docs/project/README.md`。
> 前置：`archive/2026-11-19-v3.2.0-packed-freeze-design.md`（已验收发布）。

## 1. 背景与目标

v3.0.0~v3.2.0 实现了召唤弹开、拖拽挤开与满屏熔断：便签之间相互碰撞、尽量避免重叠。开发者的主便签希望永远固定在原地，不受其他便签移动的挤压影响。目标行为（会话确认）：

1. **新概念「钉住」（Fixed）**：钉住的便签不被其他便签的挤压弹开推动（既不会被弹开、也不会被装箱挪位），但它依然可以被用户拖动、缩放，并且**用户自己拖动/缩放钉住便签压到别的便签上时，别的便签照常被挤开**——「钉住」只保护自己不被推，主动拖动是用户的明确意图。
2. **原「钉住」改名「置顶」（Pinned）**：现有「钉住」按钮（保持最上层）改名为「置顶」，行为完全不变，只改 UI 文案。两个开关相互独立、可叠加。
3. **头部按钮收敛**（2026-11-20 手测反馈修订：置顶使用频率低收进菜单、复制提回头部）：便签头部按钮为三键「钉住 / 复制 / 更多」，其中「更多」下拉菜单收纳「置顶 / 设置（样式）/ 销毁」——解决五键并排的拥挤问题。

## 2. 行为规则（会话确认）

1. 钉住便签**永不被程序性位移**：召唤落地弹开、拖拽实时挤开、记账兜底弹开、装箱兜底，都不选钉住便签作为被弹者。
2. 钉住便签**仍是障碍**：可推便签的四向滑移落点与装箱兜底落点都必须避开钉住便签的矩形（钉住矩形并入「已落地矩形集」，与 self 同等地位）。
3. 钉住便签作为**主动方**（用户拖动/缩放/召唤它）时与其他便签完全同权：原位落地、挤开别人，没有任何特殊化。
4. 满屏熔断（v3.2.0）语义不变：`packed` 见证只来自**可推便签**的「四向+装箱全部无解」。若重叠对手全是钉住便签，接受重叠但不触发熔断（桌面未必塞不下，只是对方不让；每 tick 空转无弹开，开销可忽略）。可推便签因钉住障碍导致无解 → 照常视为塞不下见证、照常熔断（静止的实际效果一致）。
5. 钉住与置顶独立：钉住不改变层级（不置顶、不沉底），置顶不改变挤压行为。钉住便签隐藏/召唤/销毁/样式/标题等其余行为与普通便签一致。
6. 钉住状态持久化（notes.json 记录字段），重启恢复。
7. 「已钉住」「已置顶」按钮激活态字色与便签生效底色同源（沿用 `--note-pin-ink` 机制）。

## 3. 数据模型（方案 A：增量字段，无版本迁移）

- `NoteRecord` 加 `Fixed bool json:"fixed"`（钉住）；`Pinned` 字段名与 JSON 键**不改**（避免 hydrate/事件/CSS/测试大面积重命名），注释改为「置顶（保持最上层）」。
- notes.json 形状版本**保持 v3 不动**：新增可选 bool 字段，旧文件缺省零值即 false，无需迁移代码（与 v2→v3 增量迁移先例同方向，但这次连就地重写都不需要）。
- 新建记录 `Fixed=false`。`ToggleFixed` 刷 `UpdatedAt`（与 `TogglePinned` 同款，钉住视为一次活跃操作）。

## 4. 挤压链路改动（核心）

- `push.go`：`PushNote` 加 `Fixed bool`。
- `ResolveOverlaps(self Rect, notes []PushNote, screenW, screenH float32)` 签名不变：初始化时把 `Fixed=true` 的候选矩形**预先并入 `landed`**（静态障碍）、标记 `processed`——它们不进扫描循环、永不产生 Push、失败也不置 packed；可推便签的 `slideDisps`/`PackTopLeft` 自然避让钉住矩形（滑移越障迭代与装箱复核都以 landed 为障碍集）。
- `pushPass`：组装候选时从 `n.rec.Fixed` 取值填入（self 不进候选，主动方无特殊化）；其余逻辑零改动。
- 调用链零改动：`summonNote` / `DragLiveTick` / `NoteMoved` / `NoteResized` / `BeginDragSession` 不动。
- 并发形态不变（PushNote 在锁内组装，纯函数锁外解析）。

## 5. 控制器与事件

- `Controller.ToggleFixed(id string)`：镜像 `TogglePinned`——取反 `rec.Fixed`、刷 UpdatedAt、`ops.SetFixed`、防抖落盘。
- `WindowOps` 加 `SetFixed(id string, fixed bool)`：无窗口层变化，只发前端同步事件 `note:fixed-sync`（载荷 `{id, fixed}`，同 `note:pinned-sync` 模式）。
- `Hydrate` 载荷加 `"fixed": rec.Fixed`。
- Go 侧注释/文档措辞：`Pinned` 相关注释统一改「置顶」表述（`TogglePinned` 方法名保留，注释改「置顶切换」）。

## 6. 前端 UI

（修订：2026-11-20 手测反馈调整——置顶使用频率低收进菜单、复制提回头部；菜单默认外露系 `display:flex` 压过 `hidden` UA 样式，显式补 `[hidden]` 规则；面板底色改与便签背景同源。）

- **note.html 头部**：`note-actions` 改为三键——`btn-fix`（钉住）、`btn-copy`（复制，提回头部）、`btn-more`（更多）。原 `btn-pin`/`btn-style`/`btn-destroy` 移入「更多」菜单。
- **更多菜单**：新增小下拉面板（锚定在 btn-more 下方），三项文字条目：置顶（原置顶切换）/ 设置（打开现有样式面板）/ 销毁（原 `requestDestroy` 流程）。点击便签其他区域、再次点击更多、或 Esc 关闭；面板底色用 `--note-bg`（与便签背景一致）、禁高饱和撞色、无 emoji 图标（如需图标用 Material Symbols）；显式写 `.note-moremenu[hidden] { display: none }`（作者样式会压过 hidden 属性的 UA 默认）。
- **note.js**：
  - 按钮文案：置顶按钮（菜单内）`已置顶/置顶`（title：置顶（保持在最上层）/取消置顶）；钉住按钮（头部）`已钉住/钉住`（title：钉住（不被其他便签挤开）/取消钉住）。
  - `refreshPinBtn` 拆为置顶、钉住两个刷新函数（或合并带参）；钉住/置顶激活态复用 `--note-pin-ink` 字色。
  - 事件：监听 `note:fixed-sync`（防串台同款 id 过滤）；toggle 发事件给 Go（同现有 pin toggle 通道模式）；hydrate 读 `data.fixed`。
- **样式面板/确认浮层**：打开时关闭更多菜单；更多菜单与样式面板互斥打开（简化：任一打开即关另一个）。
- **index.html**（设置窗口）：集合切换键帮助文案「未钉住的自动钉住」→「未置顶的自动置顶」。

## 7. 版本收尾

`settingsui.Version` → 3.3.0；`changelog.js` 补 v3.3.0 条目（钉住/置顶/更多菜单）；CLAUDE.md 同步版本段落与关键领域规则（钉住语义、「更多」菜单结构）。`WindowOps` 新增 `SetFixed` 不改服务形状，**无需重新生成绑定**（settingsui.Service 未动）。

## 8. 测试

单测（go test，WindowOps 内存替身）：

- `ResolveOverlaps` 钉住分支：钉住候选不被推（无 Push）；可推便签落点避开钉住矩形（滑移与装箱两路）；重叠对手全钉住 → 接受重叠且 `packed=false`；可推便签因钉住障碍无解 → `packed=true`；钉住不参与级联（级联落点撞钉住 → 继续避让或接受重叠）。
- 控制器：`ToggleFixed` 翻转 + UpdatedAt 刷 + 落盘；召唤/拖拽压钉住便签 → 钉住不动、pushes 不含它；拖动钉住便签自身 → 仍挤开别人。
- store：round-trip 保留 `fixed` 字段；旧 v3 文件（无 fixed 键）读入为 false。

手测闸口（全部通过才算交付）：

1. 钉住 A 后拖便签 B 压上：A 不动（接受重叠/或 B 落点避开），B 正常弹开或覆盖。
2. 拖动钉住便签 A 本身压 B：B 照常被挤开。
3. 召唤落地压钉住 A：A 不动，召唤者原位（与其他被接受重叠语义一致）。
4. 置顶按钮：改名正确、激活态「已置顶」、置顶/沉底行为与原钉住一致。
5. 钉住+置顶叠加：置顶生效且不被挤。
6. 更多菜单：置顶切换生效（菜单内激活态「已置顶」）、设置开样式面板、销毁走 Y/N 确认；头部「复制」生效；点击空白/Esc 关闭菜单；与样式面板互斥；菜单默认收起不外露、面板底色与便签背景一致。
7. 重启恢复：钉住态、置顶态均保留。
8. 设置窗口帮助文案与更新日志（v3.3.0 条目 + 当前版本高亮）。
9. `go build ./...` + `go vet ./...` + `go test ./...` 全绿。
