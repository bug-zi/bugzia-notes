>
> **修订二（2026-11-26 24:00 前后，会话追加）**：新增**悬停 Ctrl+滚轮调整图片显示大小**——token 扩展可选后缀 `![img](picture/<名> =<宽>)`（px，高度按比例自动）；前端 40~2000px 每档 ±40（上滚放大/下滚缩小），基宽取当前 token 宽（未指定取实际显示宽），即时生效 + 400ms 防抖写回 content（`SetContent` 只落盘不重推，滚动过程中 DOM 稳定，不调 render 防打断连续滚动）；`preventDefault` 拦掉 WebView2 的 Ctrl+滚轮页面缩放（wheel 监听须非 passive）；Go `pictureTokenRe` 同步兼容后缀（名称组恒第 1 组，`ExtractPictureRefs`/GC 不受影响），` =99999` 超宽后缀不匹配（当普通文本行，防脏数据）。

## 1. 背景与目标

辅助/自由便签正文当前只支持文本（v4.1.0 MD 渲染也明确排除图片）。目标（会话确认）：

1. **复制粘贴图片到便签**：编辑态 Ctrl+V 粘贴剪贴板位图（截图工具、浏览器右键复制图片等来源），图片文件落盘 exe 同目录 `picture\`。
2. **正文内缩略显示**：阅读态按 token 位置内嵌缩略图（max-width 适应便签宽），编辑态显示 token 源文本。
3. **点击图片用系统默认图片查看器打开**（会话确认），复用 `app.Browser.OpenFile`（内部 `internal/browser.OpenFile`，走系统默认文件处理程序）。

范围（会话确认）：

- **仅辅助便签（slot 1~5）与自由便签（slot -1）**；主便签（slot 0）不支持——保持纯文本待办语义，note-todo.js 不加图片处理。
- 图片文件生命周期：**启动时自动清理**（会话确认）——GC 扫描全部便签与回收站的引用，删无引用文件。
- 资源管理器「复制文件」（CF_HDROP）不在本版范围（WebView2 paste 事件拿不到文件路径）。

方案取舍（已定）：显示采用 **AssetServer 自定义路由**（方案 A，会话确认）——content 存纯文本引用 token，webview 经 `/picture/<名>` 路由读磁盘文件；否决 base64 data URL 内嵌（重启恢复需新增读图服务、异步渲染、DOM 内存驻留大）。token 采用 **MD 图片语法同形**（会话确认），MD 渲染模式下语义自然。

## 2. 数据形态（notes.json v3 零迁移）

1. 图片引用 token：`![img](picture/<文件名>)`，**独占一行**。与 MD 图片语法同形，但渲染不依赖 md.js（两种模式统一由渲染层特判，md.js 不动）。
2. 文件名格式 `YYYYMMDD-HHMMSS-<4位随机小写字母数字>.<ext>`（如 `20261126-223000-a1b2.png`）；ext 白名单 `png/jpg/webp/gif`（mime `image/jpeg` 归一为 `jpg`），由剪贴板 `getAsFile()` 的 mime 推断。
3. notes.json 仍 v3 形状，content 语义扩展（同 v4.0.0 待办行先例），零迁移零重写。
4. 复制按钮照旧复制源码 content（含 token 文本）。

## 3. 粘贴链路（前端 note.js，仅 slot≠0）

```
ta paste 事件 → clipboardData.items 找 image/*（取第一个；没有则不拦截，放行默认文本粘贴）
→ e.preventDefault() + getAsFile() → FileReader 读为 base64（dataURL 去头）
→ Call.ByName(NS + "SavePicture", ext, base64) → Go 落盘返回文件名
→ 在光标处插入 token（当前行非空则光标前补 \n，token 后补 \n，保证独占一行）
→ 走既有 note:changed 提交通道（draft 同步、防抖落盘、重推回显均不变）
```

1. 保存期间粘贴框状态保持，成功后更新 `ta.value` 与光标；失败（返回 error）→ log + 现有 Notify 通道提示（不新增 UI 组件）。
2. 大小上限 **20MB**（Go 侧解码后校验，超限报错不落盘）。
3. 主便签 slot=0 的编辑态（note-todo.js）不挂 paste 处理：粘图无效果，天然维持纯文本。
4. 编辑态 textarea 里 token 就是源文本（与 v4.1.0 MD 源码语义一致）；Esc 取消可还原含 token 的粘贴草稿。

## 4. Go 侧改动

1. **picture 目录解析**（main.go，与 `configDir()` 并排同模式）：`pictureDir()` = exe 同目录 `picture\`，`go run`/`go test`（exe 在 go-build 临时目录）回退工作目录 `picture\`；`os.MkdirAll` 惰性建目录（SavePicture 时）。
2. **`settingsui.Service.SavePicture(ext, base64 string) (string, error)`**：ext 白名单校验 → base64 解码 → 20MB 上限 → 文件名生成（时间戳 + 4 位随机）→ tmp/rename 原子写（store 同款模式）→ 返回文件名。Service 构造注入 pictureDir（main.go 传入）。改服务后 `wails3 generate bindings`。
3. **资产路由（main.go）**：`Assets.Handler` 包一层 `pictureHandler`——URL path 匹配 `/picture/<名>` 且名过**严格文件名格式** `^\d{8}-\d{6}-[a-z0-9]{4}\.(png|jpg|webp|gif)$`（注意宽松白名单 `[\w.-]+` 会放行 `..`——`/picture/..` 即指上级目录，必须用严格格式堵死）且文件存在于 pictureDir → `http.ServeFile`（自动 Content-Type）；其余请求原样转发 `BundledAssetFileServer(assets)`。
4. **打开查看器（main.go 事件订阅）**：`note:openimage {id, name}` → 复核文件名严格格式 + 文件存在（纵深防御，同 `note:openlink` 复核前缀先例）→ `app.Browser.OpenFile(绝对路径)`；失败仅 log。

## 5. 前端显示（note.js / note.css）

1. `render()` 重构为按行混排：content 按行分割，token 行（正则 `^!\[img\]\(picture/(\d{8}-\d{6}-[a-z0-9]{4}\.(?:png|jpg|webp|gif))\)$` 整行匹配，与后端严格格式同形）→ `<img class="note-img">` 元素（dataset.name 存文件名）；连续非 token 行合成文本段（mdOn 段用 `mdRender` 包裹、否则 textContent 的 div），既有转义安全策略不变。
2. 图片点击（阅读态）→ `wails.Events.Emit("note:openimage", { id, name })`。
3. note.css：`.note-img` max-width 100%、圆角、hover 微亮边框（玫红主题色系，硬性规则 2/3：无 emoji、无高饱和撞色）、cursor:pointer；加载失败（文件已被 GC/损坏）显示占位文本行。
4. 编辑链路零改动：`syncTextareaHeight`、IME、`commitEdit`、`note:changed` 照旧。

## 6. 启动时 GC

1. 时机：main.go `store.New` 之后、窗口创建之前（`application.New` 前后均可，选窗口创建前）。
2. 引用集 = notes.json 全部 `rec.Content` + recycle.json 全部 entry content 中提取的 `picture/<名>`；提取逻辑纯函数化（如 `store.ExtractPictureRefs(contents []string) map[string]bool`）可单测。
3. 遍历 pictureDir，不在引用集的文件删除（逐个 log）；目录不存在/为空安全跳过。
4. 时序边界自洽：粘贴写盘后 400ms 防抖窗口内进程被杀 → token 未进 content → 文件成孤儿 → 下次启动 GC 收走。

## 7. 测试

1. Go 单测：`SavePicture`（文件名格式/ext 白名单/超 20MB 拒绝/原子写/非法 ext 报错）、`ExtractPictureRefs`（多行提取/去重/无引用空集）、GC（删无引用/留已引用含回收站引用/目录不存在安全）。
2. 手测闸口（全部通过才算交付）：
   - 截图工具贴图 / 浏览器右键复制图片贴图 → token 入正文、缩略图显示；
   - 点击缩略图 → 系统默认图片查看器打开；便签窗口不导航；
   - 重启恢复图片显示；MD 渲染开/关两模式下图片均正常（其余 MD 元素不受混排影响）；
   - 删掉 token 行重启 → picture 文件被 GC；
   - 主便签粘图无效果；辅助便签文本粘贴、IME、编辑往返不受影响；
   - 超大图（>20MB）失败提示；`/picture/..` 与非法名路由请求被拒（不泄漏上级目录）；中文路径、免安装目录移动后（exe+data+picture 整体搬）仍正常。
3. 回归：`go build ./...` + `go vet ./...` + `go test ./...`；既有手测项抽查（贴图不涉及主便签/召唤/挤开链路，抽查便签编辑与 MD 渲染即可）。
