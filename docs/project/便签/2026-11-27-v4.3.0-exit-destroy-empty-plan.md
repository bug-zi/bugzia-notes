**Goal:** 退出应用（托盘退出 / 自更新重启）时静默销毁全部空便签（无文字无图片的辅助/自由便签；主便签永不销毁；置顶/钉住/样式锁不豁免）。

**Architecture:** `Controller.DestroyEmptyNotes() int` 锁内收集空便签（`slot != SlotMain && strings.TrimSpace(Content) == ""`）→ 逐张 `removeNote` + `delete(visible)` + 清 `activeID` → 锁外 `ops.CloseNote` + `scheduleSave`（退出段随后 `st.Close()` flush 落盘）；main.go 退出清理段 `st.Close()` 前一行接线。

**Tech Stack:** Go（Wails v3.1.0 本地补丁副本）；前端零改动。

**Spec:** `docs/project/便签/2026-11-27-v4.3.0-exit-destroy-empty-design.md`

**背景事实（执行者零上下文必读）：**

- 既有销毁链参考（controller.go:864 `ConfirmDestroy`）：`c.notes = removeNote(c.notes, id)` → `delete(c.visible, id)` → 清 `c.activeID` → 解锁 → `c.ops.CloseNote(id)` → `c.scheduleSave()`；非空才 `AddRecycleEntry`。空便签销毁复用同一清理形态、**不**入回收站。

```go
// DestroyEmptyNotes 退出时静默销毁全部空便签（v4.3.0）：辅助/自由便签
// content 去空白后为空即销毁（主便签永不销毁；置顶/钉住/样式锁不豁免）。
// 空便签不入回收站（与 ConfirmDestroy 非空入站语义一致）。返回清理张数。
func (c *Controller) DestroyEmptyNotes() int {
	c.mu.Lock()
	empty := make([]string, 0, 4)
	for i := range c.notes {
		rec := c.notes[i].rec
		if rec.Slot != model.SlotMain && strings.TrimSpace(rec.Content) == "" {
			empty = append(empty, rec.ID)
		}
	}
	for _, id := range empty {
		c.notes = removeNote(c.notes, id)
		delete(c.visible, id)
		if c.activeID == id {
			c.activeID = ""
		}
	}
	c.mu.Unlock()

	for _, id := range empty {
		c.ops.CloseNote(id)
	}
	if len(empty) > 0 {
		c.scheduleSave()
	}
	return len(empty)
}
```
