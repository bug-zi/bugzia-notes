# 便签（便签窗口核心）

介绍：每张便签一个独立的 OS 级无边框透明浮层窗口，是应用的核心交互面；承载编辑、层级、定位、销毁等全部便签行为。
本文档由 AI 根据已批准的 v1 主体设计（`../全局/archive/2026-11-16-bugzia-notes-app-design.md`）起草，**当前为草稿待开发者审核**，审核定稿后为需求正本。

v1（草稿待审核）：

**窗口模型：**

- 每张便签一个独立无边框透明浮层窗口；窗口 Name/Title = 便签 id，全局唯一
- 钉住（置顶）/ 未钉（沉底到桌面层）双层模型：钉住恒置顶，未钉沉底到桌面层（被其他窗口覆盖）
- 只有钉住便签持久化；临时便签（未钉）仅内存，应用退出即消失
- 头部拖动移动窗口；边缘可缩放（min 160x120，默认 240x220）
- 便签上限 50 张，达到上限经提示拒绝新建

**编辑交互：**

- 点击正文进入编辑；Enter 提交、Shift+Enter 换行、Esc 取消、失焦自动提交
- 内容高度自适应、保持末行可见；中文 IME 正常输入（候选词跟随光标）
- 销毁带确认（按钮 / Y/N 键盘确认，`alt+z` 销毁最近编辑的便签）
- 支持复制便签内容

**定位与恢复：**

- 新便签默认屏幕左上角贪心装箱：贴紧已有便签无间隙、行满换行、不出屏、避开用户手动挪过的便签
- x/y = -1 哨兵表示「未被用户放置」；程序性摆放不写回坐标，只有用户拖动才落盘
- 重启后钉住便签按持久化数据恢复（几何、内容、层级、样式）

**样式：**

- 默认样式 = 用户 bugzia 实际配置（配置迁移自动带入）；无迁移时回退玫红 #C95877 底白字、bg_alpha 0.9、圆角 10、字号 14
- 样式改动经设置窗口对全部便签实时生效

**边界：**

- v1 不做：Markdown / 富文本、便签管理面板（搜索/列表/回收站/标签）、per-note 独立样式（数据格式预留字段）、数据云同步
- 只在 Windows 10/11 验收，不做其他平台适配调优
